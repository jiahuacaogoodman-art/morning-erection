# ADR 0005：模型输出只是提案

- 状态：已采纳（v0.2）
- 关联：RFC §5、§7、T11、T12

## 决定
- 模型只能在规则判定为 `JUDGE` 的地方被调用，输出经 `admit_model_decision` 与授权策略
  重新准入；模型声称的权限（`model_claims`、`suggested_capabilities`、正文里的"已批准"字样）
  一律不扩大 `effective_authority`。
- 审批绑定到精确的 `payload_digest`、grant 版本与过期时间；内容修订生成新 effect_key（`#revN`），
  旧审批失效。
- 回放（§14）只重新准入**已记录**的模型输出，从不调用模型，也不接触工具。

## 不在本 ADR 保证范围内
状态机与准入测试只证明"模型说什么都越不过边界"，**不**证明模型判断本身可靠。
按 RFC §18，模型的召回率、误报率和提示注入鲁棒性需要单独评测并单独报告；v0.2 未做。
