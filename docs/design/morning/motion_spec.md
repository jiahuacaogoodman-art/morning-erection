# Morning：分层日出 Logo

本规范取代之前的线条太阳方案。现在以立体日出雕塑为唯一图形标识：品牌区、侧栏、欢迎画面、对话头像、输入框和 favicon 共用一套几何。保留 morning. 字标。

## 图层与素材

原始参考是 `apps/pulse/public/morning-sunrise.png`。当前素材是重新构建的可编辑 SVG，不再把该 PNG 作为运行时 Logo。

| 图层 | 完整几何 | 表现 |
| --- | --- | --- |
| 太阳 | 完整圆形，遮挡区域仍存在 | 橙色渐变、边缘光、细颗粒 |
| 后层片 | 独立封闭贝塞尔曲面 | 浅色材质、薄侧边与高光 |
| 前层片 | 独立封闭贝塞尔曲面 | 向右收拢的波形、接触阴影 |
| 底座 | 完整碗形与口沿 | 深色陶质渐变、独立接触面 |
| 辅助阴影 | 单独椭圆 | 随组装显现，分层查看时跟随底座 |

每个实体都有 `data-part`、`data-enter`、`data-live` 三层分工：分别负责交互位移、入场、持续状态。动画互相叠加，不会争用同一个 transform。运行时 SVG 的 ID 按 React 实例分配；对话里多个 Logo 共存不会串用渐变或裁切。

## 动效

气质：温暖、稳重、轻盈。使用 Staging、Slow In/Slow Out、Timing、Follow Through 和 Appeal。

| 场景 | 时间 | 动作 |
| --- | --- | --- |
| 启动 / 重播 | 1600 ms，品牌区缩为 1100 ms | 底座先稳住，后层片、前层片依次合拢，太阳从其后升起并轻微收稳 |
| 工作中 | 3200 ms 循环 | 太阳轻升，前后层片反向微倾，底座保持稳定 |
| 悬停 / 聚焦 | 320 ms | 太阳抬起，前后层片各自错开 |
| 分层查看 | 650 ms | 太阳与曲面、底座拉开，四层可分别开关 |
| 减少动态效果 | 0 ms | 默认直接显示组合终点；手动分层查看即时切换 |

所有入场部件使用同一时钟，阶段写入各自的关键帧；没有整图上下漂浮，也没有保留旧线条图标。关键帧缓动为显式 cubic-bezier，避免浏览器丢弃变量形式的缓动。

静态 Logo 不持续运动。只有当前工作的输入框标记使用循环；头像保持静态。欢迎图可点击重播。SVG 的 innerHTML 对象保持稳定，状态轮询不会重建节点并反复重启动画。入场结束后清理已完成的动画样式，恢复静态姿态与材质，避免滤镜缓存让终点变软。

## 文件

- `apps/pulse/public/morning-logo.svg`：唯一几何源，四个独立实体和一个阴影。
- `apps/pulse/src/Brand.tsx`：所有产品入口共用的组件。
- `apps/pulse/src/brand.css`：生产动效。
- `apps/pulse/public/mark.svg`：同一图形的紧凑 favicon 取景。
- `docs/design/morning/logo.svg`、`motion.css`：可独立使用的副本。
- `logo_motion.html` / `apps/pulse/public/logo-motion.html`：同源交互预览，支持重播、暂停、调速、时间定位、分层和逐层开关。
- `build_logo_preview.py`：从生产 SVG/CSS 重新生成上述副本和预览，不维护另一套标记。

## 验证与差异

进行了 4 轮原图对照。按 alpha > 160 的主体轮廓比较，最终 IoU 为 0.972201；原图独有 1167 像素，SVG 独有 14668 像素。半透明光晕和接触阴影不属于该轮廓指标。太阳、层片和底座的形状与交叠关系保留；摄影般的表面细节用渐变和程序纹理重建，并非逐像素复制。

边界使用圆形、椭圆和少量三次曲线，无像素网格描边。路径审计剩余的角度提示位于层片的右上切边和被遮挡的左端收口，是有意的实体边角；连续曲面连接处的 9° 偏折已经修正。边缘与分层图均已目视检查。

`outputs/motion-qa.json` 记录了渲染验证：

- 动画最终帧、实际播放结束后的保持帧与静态 SVG 终点相差 0 像素。
- 3200 ms 循环接缝及前后 1 ms 的帧相差 0 像素。
- 减少动态效果时没有活动动画，渲染与静态终点相同。
- 300 / 700 / 1100 ms 各图层的实际 transform 不同，确认运动发生在独立层上。
- 预览的分层、逐层开关、重播和即时调速可用；无重复 ID、页面错误或 Axe 违规。
- 1280 和 390 像素宽度无横向溢出。
- 正式页面检查到 16 个新 Logo 实例，旧线条 Logo 和原 PNG Logo 引用均为 0；既有对话与驻守状态保留。
- 前端构建和 Ruff 检查通过；4 项正式页面测试通过，覆盖重播完成与实时状态轮询期间 SVG 节点持续保留，避免动效反复重启。

几何拟合、对照图、动画关键帧和 GIF 位于 `outputs/`。使用 `outputs/fit_work/check_geometry.py` 继续拟合；使用 `outputs/verify_motion.py` 重跑渲染与交互检查。它们需要 Pillow、NumPy（仅几何检查）和 Playwright，可用 `uv run --no-project --with pillow --with numpy --with playwright python ...` 运行。
