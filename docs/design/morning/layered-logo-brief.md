# 立体日出 Logo：替换与分层动效

本轮明确以 `morning-sunrise.png` 的立体日出雕塑为唯一品牌图形，替换线条太阳。保留 morning. 字标。

气质：温暖、稳重、轻盈。以原图的橙色太阳、两片交叠的浅色曲面、深色陶质底座为四个实体图层；地面接触阴影作为第五个辅助图层。光从右上方照入，保留原图明暗关系。

选择少量圆形与三次贝塞尔曲线重建立体图形。保留完整太阳和两片曲面的遮挡部分，展开时不会露出切图空洞。渐变、边缘厚度、接触阴影和程序纹理属于各自图层。源 PNG 仅作为拟合参考。

全站使用同一 SVG：品牌区、侧栏图形、欢迎画面、消息头像、输入框标记、处理状态和 favicon。仅调整显示尺寸；不保留另一种线条版标记。

## 动作约定

- 启动 / 点击重播：1600 ms 共同时钟。底座先落定，前后曲面先后合拢，太阳从其后升起，最后轻轻收稳。曲面先后偏移约 10%–15% 的总时长。
- 处理中：3200 ms 循环。太阳轻升，前后曲面反向轻微倾动，底座保持稳定，首尾一致。
- 悬停 / 键盘聚焦：320 ms。太阳抬起，前后层片分别错开，离开后还原；小头像的幅度更小。
- 专用预览：可暂停、逐时刻定位、调速、查看分层展开和逐层显示。整个图形平移不算分层动效。
- 减少动态效果：直接呈现静态组合。应用不因为 Logo 动画阻塞交互。

验收：原图与 SVG 的轮廓/材质比较、200% 边缘检查、完整遮挡几何检查、分层关键帧、循环接缝、静态最终帧一致性，以及实际页面各个 Logo 入口。
