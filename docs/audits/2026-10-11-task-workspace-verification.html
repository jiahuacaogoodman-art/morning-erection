Agent → 原生会话 → 并发与恢复

限定场景已验证

  • 每个已载入会话拥有独立 Pi 原生运行时，保留工具、扩展、上下文、历史和消息队列
  • 切换页面不会中止其他会话；按会话停止；默认载入上限 4，可设置 2–8
  • 浏览器标签页绑定会话，草稿按会话保存，迟到响应不覆盖另一段会话
  • 空会话重启保留模型与思考深度；有对话的会话沿用 Pi JSONL，不修改原生保存语义
